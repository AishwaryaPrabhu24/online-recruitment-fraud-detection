# Online Recruitment Fraud Detection System

## Project Overview

The Online Recruitment Fraud Detection System is a machine learning-based application designed to identify fraudulent job postings and distinguish them from genuine job opportunities.

The system analyzes job descriptions and other job-related information using Natural Language Processing (NLP) and machine learning techniques.

## Technologies Used

- Python
- Flask
- Machine Learning
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Scikit-learn
- XGBoost
- Random Forest
- Linear SVM
- SMOTE
- SHAP

## Machine Learning Workflow

1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Text Feature Extraction using TF-IDF
4. Additional Job-Related Feature Extraction
5. Handling Class Imbalance using SMOTE
6. Model Training and Evaluation
7. Model Explainability using SHAP
8. Flask Web Application Integration

## Dataset

Fake Job Postings Dataset.

## Machine Learning Models

- Random Forest
- Linear Support Vector Machine (SVM)
- XGBoost

## Application Features

- Job posting fraud detection
- Fraud probability prediction
- Red-flag identification
- Important word analysis
- Prediction visualization
- Genuine or fraudulent classification

## Project Structure

The project contains dataset, preprocessing, model training, trained model artifacts, and Flask application components.

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Run the Flask application.
4. Open the application in your browser.
